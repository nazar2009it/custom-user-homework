# Фактически выполненные проверки

Дата: 13 октября 2026 года.

## Проверено

На Python 3.12.14 и доступной копии Django 6.0.7:

- Синтаксис Python-файлов проекта.
- Создание начальной миграции `users/0001_initial.py`.
- Применение миграций к новой SQLite-базе.
- Django `check` для модели пользователя и админки: ошибок нет.
- 12 тестов модели, менеджера и формы создания пользователя: все прошли.
- Вход в админку по email, в том числе с другим регистром букв.
- Открытие списка пользователей, формы создания и формы изменения.
- Создание обычного пользователя через форму админки без телефона: успешно; пароль хранится в виде хеша.

## Что остаётся проверить после установки зависимостей

Django REST Framework и drf-spectacular в среде подготовки установить не удалось. Поэтому проверки выше выполнялись с отдельной конфигурацией, включающей Django и приложение `users`, без API-приложений.

Регистрация и вход через API, запрос с токеном и Swagger **не проверены запуском**. Полный набор API-тестов включён в `users/tests/test_api.py`. Точное поведение полного проекта необходимо подтвердить командами ниже.

В Windows из папки с `manage.py`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test users
.\.venv\Scripts\python.exe manage.py spectacular --file schema.yml --validate --fail-on-warn
```

Затем запусти сервер и пройди примеры из README в Swagger.
